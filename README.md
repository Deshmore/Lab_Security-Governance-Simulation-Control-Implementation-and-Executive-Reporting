# Lab_Security-Governance-Simulation-Control-Implementation-and-Executive-Reporting
GRC102 Security Governance Simulation Assessment Brief

Purpose
This practical assesses your ability to translate a security governance case study into an evidence based technical and management response. You will build an isolated simulation, identify the governance failures, implement and verify appropriate controls, then present results through security metrics and executive reporting.
Official Lab Instructions
Use the official ICDFA repository instructions throughout this assessment: https://github.com/icdfa/grc-engineering-labs/blob/master/phase1/grc102/week8/LAB_INSTRUCTIONS.md

Scenario
You are the Security Governance Analyst for a fictitious organisation with a customer facing web application, a customer data environment, and weak governance oversight. The isolated lab is modelled on failures associated with the Equifax breach, including delayed remediation, weak database authentication, insufficient segmentation, ineffective monitoring, and weak accountability. Your task is to document the baseline, analyse the failures, implement controls, and report the improved posture to management.

Learning Objectives
•	Build and document an isolated Docker based security governance simulation.
•	Identify governance failures using vulnerability, configuration and monitoring evidence.
•	Relate the laboratory findings to governance lessons from the Equifax case study.
•	Implement and verify governance controls for patching, monitoring, segmentation, database security and executive oversight.
•	Produce meaningful governance metrics, an executive dashboard and a board level report.

Safety and Authorised Scope
Complete every task only in a local or ICDFA provided isolated Ubuntu and Docker environment. Do not scan, test or attempt to access any public, organisational or third party system. Do not use real personal data, credentials, public IP addresses or secrets. Keep the intentionally vulnerable application inside the authorised lab network and do not expose it to the internet.
